# Theme Calendar palette sources

The 187 Monkeytype counterparts adapt the theme names and colour values in the
[Monkeytype theme catalogue](https://github.com/monkeytypegame/monkeytype/blob/46e93f27482ccb8aff62c4baca0cefa882da53dd/frontend/src/ts/constants/themes.ts).
Copyright belongs to the Monkeytype contributors and theme creators. The
upstream project uses [GPL-3.0](MONKEYTYPE-LICENSE.txt). The catalogue applies
these colours to BRTA's interface and adds 179 BRTA editions.

Run `python scripts/build_theme_calendar.py /path/to/themes.ts` from the
repository root to regenerate the catalogue from the pinned source.
