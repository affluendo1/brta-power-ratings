# WDTA aggregate score data

`aggregate-scores.json` contains score frequencies from local current and historical WDTA collection snapshots. Each row counts a score, competition, season and discipline, with counts below five suppressed. It has no player names, teams, fixture identifiers, contact details or source pages. It is not a player-level training dataset.

The historical checkpoint is incomplete. The two snapshots can overlap; do not add their counts as independent observations. Score formats and source entries have not all been independently validated. See the [WDTA source](https://www.trols.org.au/wdta/) for the original competition information.
